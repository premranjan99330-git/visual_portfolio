# Ethar AI · Data Science & ML Portfolio

> **5 production-grade interactive dashboards** built with HTML/CSS/JS — no frameworks, no build step, just open in browser.

---

## Dashboards

| # | File | Description |
|---|------|-------------|
| 01 | `01-neural-training-monitor.html` | Real-time neural network training monitor — loss curves, layer activations, confusion matrix, live GPU utilization |
| 02 | `02-llm-token-analytics.html` | LLM token analytics — probability heatmap, model throughput comparison, cost breakdown, token distributions |
| 03 | `03-model-leaderboard.html` | ML model leaderboard — MMLU / HumanEval / GSM8K benchmarks, sparklines, sortable rankings |
| 04 | `04-api-monitor.html` | AI API monitoring dashboard — live request volume, endpoint latency, error log, geo traffic |
| 05 | `05-eda-explorer.html` | EDA / Dataset Explorer — histograms, scatter plots, correlation matrix, feature importance, summary stats |

---

## Quick Start

```bash
git clone https://github.com/YOUR_USERNAME/ethar-ai-portfolio
cd ethar-ai-portfolio
# Open any file in your browser — no server needed
open 01-neural-training-monitor.html
```

Or serve locally:
```bash
python3 -m http.server 8080
# → http://localhost:8080
```

## Design System

All dashboards share a bold, editorial aesthetic with strong color contrasts and live interactivity:

- **01 Neural Monitor** — Dark terminal / CRT scanline aesthetic · Neon accent palette
